# 第8回　推定の基礎

統計的有意・信頼係数・信頼区間の考え方を導入し、母平均の区間推定（母標準偏差が既知の場合、未知で小標本＝t分布の場合、未知で大標本の場合）を学びます。続いてカイ二乗分布による母標準偏差の推定と、母比率の区間推定を扱います。
