# 第5回　離散型確率変数

確率変数と確率分布の考え方、離散型と連続型の違いを整理したうえで、二項分布、ポアソン分布、超幾何分布、一様分布と、それらの分布同士の関係（二項分布の極限が正規分布になることなど）を学びます。
