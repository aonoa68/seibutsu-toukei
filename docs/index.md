## この授業について

実験や調査で使う統計学の基礎を一通り学ぶ授業です。前半でデータの中心傾向やばらつきの捉え方、2変数の関係の要約といった記述統計を扱い、後半では確率変数、母集団と標本、区間推定、仮説検定、分散分析、主成分分析、最尤法へと進み、一部から全体を推測する推測統計の考え方を身につけます。演習と課題では統計解析ソフトRを使います（Pythonでの解答例も一部あります）。
