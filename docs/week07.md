# 第7回　母集団と標本

全数調査と標本調査、標本誤差と非標本誤差、無作為抽出、標準誤差と信頼区間、必要標本数の考え方、有意抽出法・割当法を学び、1936年アメリカ大統領選の選挙予測の失敗を例に標本の偏りを考えます。課題では正規分布と二項分布の計算問題に取り組みます。
