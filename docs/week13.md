# 第13回　主成分分析

多次元データを少数の主成分に要約する主成分分析を、10種類の生物・5つの遺伝子の発現量という例題で学びます。標準化、共分散行列・相関行列、固有値分解、寄与率と主成分の選択、バイプロットの作成と解釈、Rでの実行方法、手法の限界を扱います。
