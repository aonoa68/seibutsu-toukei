# 第2回　1変数データの要約（対面）

Rの演習回です。irisデータを使って、データの概要の確認、平均値・中央値・四分位数・分散・標準偏差の計算、ヒストグラム・箱ひげ図・散布図の描き方、CSVの読み込み方を扱い、同じことをPython（Google Colab）で行う方法も紹介します。あわせてオンデマンド動画で度数分布・代表値・分散・標準偏差・変動係数・分布の形を学びます。

!!! note "この回について"
    対面回です（シラバスでは第3回が対面でしたが、2025年度は第2回に入れ替えて実施）。スライド末尾の課題は第4回の課題と同じものです。
