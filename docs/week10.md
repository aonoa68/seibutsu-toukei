# 第10回　適合度と独立性の検定

検定の種類を体系的に整理し、両側検定と片側検定、母平均の検定、2標本の平均・分散・比率の差の検定を概観したうえで、カイ二乗検定による適合度の検定と独立性の検定、効果量を学びます。課題では区間推定と独立性の検定をRで行います。
